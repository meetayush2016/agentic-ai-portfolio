AI / DevOps

InfraAgent — Autonomous Cloud Ops Assistant

An AI-powered remediation agent built with Python and the Claude API. InfraAgent listens to AWS CloudWatch alarm state changes via EventBridge. When an anomaly fires, it queries Claude with enriched context — metric history, recent logs, and affected resource metadata — and Claude uses tool use to decide which Ansible playbook to invoke. The agent executes the playbook via subprocess, streams output in real time, and posts a structured action summary to Slack. Every action is logged to DynamoDB with full playbook diffs for audit trails. Built as a personal exploration into agentic AI applied to infrastructure operations.
